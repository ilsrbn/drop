# Drop Syntax for VS Code

This tiny companion extension injects the TypeScript TextMate grammar into
`<drop lang="ts">` blocks in Vue SFCs. It has no language server, runtime,
or build integration.

For local development, open this directory in VS Code and press `F5`; the
Extension Development Host will highlight Drop blocks in the opened project.

Package and publish this directory as the `drop.drop-vscode-syntax` extension
when the module is ready for public distribution.
